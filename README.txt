LA MOSTRA CAPOVOLTA - sito di partenza (modello)
================================================
Apri index.html con doppio clic: funziona offline, senza server e senza internet.

COSA MODIFICARE
- js/content.js : TUTTI i testi. Le voci "[DA COMPLETARE]" vanno riscritte dalla classe
  con fonti verificate. Nei messaggi simulati, {{id|testo}} crea una frase cliccabile.
  Ogni chiave in "reveals" spiega quella frase e rimanda a una fonte (S1, S2...).
- css/style.css : colori (variabili in cima) e caratteri.
- Immagini: cartella assets/img (WebP/JPEG, max 1600 px di larghezza, ~250 KB). Audio: assets/audio (MP3 mono 128 kbps).
  Poi indicale in content.js (campo img) e aggiungi sempre il testo alternativo.

REGOLE DA NON ROMPERE
- Nessuna immagine di propaganda riprodotta: si smonta il meccanismo con parole e schemi.
- I messaggi 2027 colpiscono un gruppo INVENTATO. Non scrivere mai odio contro gruppi reali.
- Nessun pulsante di condivisione, commenti, tracker, font o script esterni.
- Ogni dato storico deve avere una fonte in "sources".

PUBBLICARE
- Zip della cartella intera (consigliato per la consegna) + QR/link se il sito e' online.
- Hosting statico (es. GitHub Pages, Netlify o server della scuola): verificate condizioni e piano.
- La consegna al concorso passa dalla scuola tramite USR: chiedete all'USR come inviare il link o il file.
